# HireOps

**Truth-first application intelligence.**

HireOps analyzes a job description against a defined library of verified candidate experience.

`JOB DESCRIPTION → REQUIREMENTS → VERIFIED MATCHES → GAPS → POSITIONING → INTERVIEW PREP`

The system deliberately keeps unsupported requirements visible instead of manufacturing experience.

## Public demo

- Job-description input
- Deterministic requirement extraction
- Verified-experience matching
- Gap detection
- Application positioning
- Interview-prep guidance
- Dependency-free responsive interface

## Technical approach

The public V2 is a self-contained HTML/CSS/JavaScript application that runs entirely in the browser, making the GitHub Pages demo portable and auditable.

## Scope

This is a portfolio prototype, not an ATS simulator or a claim about employer outcomes. A production version would add structured resume ingestion, configurable evidence records, richer parsing, application tracking, versioned resume output, and persistent job history.
