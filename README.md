# HireOps

Truth-first application intelligence for AI, automation, implementation, and support roles.

## Why this exists
Job seekers often use AI to rewrite resumes, but generic AI can invent experience. HireOps takes the opposite approach: application recommendations are constrained by a verified candidate profile.

## V1
- Paste a job description
- Extract recognizable technical requirements
- Compare them with verified experience
- Separate matched skills from gaps
- Generate a positioning recommendation
- Maintain a verified proof library

## Skills demonstrated
React, workflow design, structured candidate data, requirements matching, UI/UX, truth-constrained AI-system architecture, troubleshooting-oriented product thinking.

## Roadmap
1. Persistent application tracker
2. Resume tailoring from locked evidence
3. Application-question copilot
4. Portfolio evidence matching
5. Interview preparation
6. LLM provider integration with structured output validation
